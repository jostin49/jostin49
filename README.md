## 🚀 Proyectos Destacados
 
### ♻️ [EcoScan — Clasificación Inteligente de Residuos](https://github.com/Jostinchalan/EcoScam---Clasificacion-de-Residuos)
Sistema de IA que clasifica imágenes de residuos en 9 categorías (cartón, vidrio, metal, orgánico, plástico, etc.) usando un ensemble de 4 redes neuronales convolucionales (CNN). Incluye backend en FastAPI, frontend web y despliegue con Docker.
`Python` `TensorFlow` `FastAPI` `Docker`
 
### 🎓 [GUIOSPRO FLOSS](https://github.com/Jostinchalan/GUIOSPRO-FLOSS)
Proyecto de tesis: sistema full-stack para la evaluación de software libre (FLOSS), desarrollado como trabajo de titulación en la carrera.
`Full-Stack` `FLOSS`
 
### 📋 [CUENTIA](https://github.com/Jostinchalan/CUENTIA)
Sistema de gestión de cuentas para el control y administración de información de manera eficiente y segura.
`React` `JavaScript` `CSS`
 
### 🌾 [AgroMercado](https://github.com/Jostinchalan/AgroMercado)
Plataforma digital que conecta agricultores con compradores, facilitando la venta directa de productos agrícolas frescos.
`React` `Node.js` `MongoDB` `Tailwind CSS`
